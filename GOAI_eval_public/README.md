# 蛋白–配体结合动力学评测数据说明（公开包）

本包为发给参赛队的**公开评测数据**。体系以匿名编号命名，**不含 PDB ID**。

## 1. 数据基座与划分

以 **MISATO**（Nature Computational Science, 2024）为统一数据基座。

- **来源**：MISATO 起始于 PDBbind 中约 2 万个实验解析的蛋白–配体复合物，经半经验量子力学系统性精修，并在水环境下进行分子动力学模拟，是目前规模最大的公开小分子–蛋白质结合动力学数据集之一。
- **划分口径**：以 MISATO 原始 MD 划分为准（剔除 NeuralMD 仓库 `peptides.txt` 中的多肽条目），得到训练 **13,066** 条、验证与测试各 **1,357** 条；测试集为全新复合物。
- **评测数据**：评测使用 MISATO 公开数据与组委会独立准备的评测数据。本包为公开评测/自验证数据；**独立核验数据不随赛题发放**，用于成绩核验。
- **自建验证集**：参赛队在训练集内部自建验证集时，可按蛋白序列一致性与配体骨架相似度做去泄漏切分，以更准确地估计泛化能力。
- **资源与合规**：本方向为统一评测，不分封闭/开放榜。允许使用外部预训练势函数、基础模型或外部 MD 数据，但须完整披露来源；**且外部资源不得包含测试集复合物或其近同源体系**，以免破坏「未见」泛化的评测（MISATO/PDBbind 为公开数据，此点尤须注意）。

训练/验证划分的 PDB 列表不在本包中；请使用 MISATO 官方 MD 划分并剔除多肽条目。本包只提供评测轨迹的观测段。

## 2. 任务定义

各档次均为**推理任务**：组委会提供每条评测轨迹自第 1 帧起的前若干帧，参赛队预测其余帧。T1–T3 为主评测档次，T4 为可选加分项。

| 档次 | 观测 → 预测 | 帧间隔 | 物理时长 | 体系数 | 考察能力 |
|------|-------------|--------|----------|--------|----------|
| **T1** | 前 10 帧 → 后 10 帧 | 80 ps | 0.8 ns → 0.8 ns | 30 | 局部动力学 |
| **T2** | 前 80 帧 → 后 20 帧 | 80 ps | 6.4 ns → 1.6 ns | 30 | 较充分观测下的未来预测 |
| **T3** | 前 20 帧 → 后 80 帧 | 80 ps | 1.6 ns → 6.4 ns | 30 | 有限观测下的长期预测 |
| **T4**（加分项） | 前 10 帧 → 后 490 帧 | 1 ns | 10 ns → 490 ns | 5 | 长时程稳定性与泛化能力 |

- **T1–T3** 来自 MISATO 原生 100 帧轨迹（共 8 ns）。第 1 帧 = 原生轨迹 index 0。T1 **只截取前 20 帧**（观测 10 + 预测 10），不提供更后面的帧。
- **T4** 为组委会独立准备的长时程轨迹（500 帧、1 ns/帧、共 500 ns），**不在** MISATO 的 8 ns MD 划分中。第 1 帧 = 该长时程轨迹 index 0。

编号规则：`T{档次}-{序号}`，例如 `T1-1` … `T1-30`，`T4-1` … `T4-5`。序号不代表难度。

## 3. 目录与文件

```text
public/
  README.md                 # 本说明
  protocol.json
  T1/  T2/  T3/  T4/
    ids.txt
    manifest.jsonl
    T1-1/                   # 示例
      T1-1.pdb              # 拓扑（第 1 帧，Å）
      T1-1_obs.xtc          # 观测帧坐标（nm）
      meta.json
```

每个体系需要读取：

| 文件 | 含义 |
|------|------|
| `{id}.pdb` | 全原子拓扑，与轨迹原子顺序一一对应；含氢、无水 |
| `{id}_obs.xtc` | 观测段坐标，帧数 = `n_obs` |
| `meta.json` | `n_atoms`、`n_obs`、`n_pred`、`dt_ps`、配体残基名等 |

**不提供**未来帧。预测目标为接下来的 `n_pred` 帧，原子数与顺序必须与 PDB/`_obs.xtc` 完全一致。

### 坐标与单位

- PDB 坐标单位：**Å**
- XTC 坐标单位：**nm**（GROMACS / mdtraj 惯例）
- 时间戳：T1–T3 为 0, 80, 160, … ps；T4 为 0, 1000, 2000, … ps。**物理间隔以各体系 `meta.json` 的 `dt_ps` 为准。**
- 体系为**剥水后的蛋白–配体复合物**（T4 中可能保留钠/氯离子）

### 配体残基名

- T1–T3：`resname MOL`
- T4：`resname LIG`

### 用 Python 读取示例

```python
import mdtraj as md

top = "T1/T1-1/T1-1.pdb"
obs = md.load("T1/T1-1/T1-1_obs.xtc", top=top)
print(obs.n_frames, obs.n_atoms, float(obs.timestep))  # 10, N, 80.0
# 物理间隔以 meta.json 的 dt_ps 为准；预测应写出 n_pred 帧、相同 N 个原子的 xtc（nm）
```

## 4. 提交约定（公开评测）

对每个体系提交一条预测轨迹：

- 文件名：`{id}_pred.xtc`（例如 `T1-1_pred.xtc`）
- 帧数：等于该档 `n_pred`
- 原子数与顺序：与 `{id}.pdb` 一致
- 单位：nm


## 5. 合规提醒

允许外部预训练势、基础模型或外部 MD，须披露来源。外部资源**不得包含本评测轨迹对应的测试复合物或其近同源体系**。请勿尝试根据序列或结构反查并使用该复合物的实验/模拟轨迹作为预测。
