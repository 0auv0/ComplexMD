# ComplexMD 阶段结果

## MISATO 全量测试

测试集包含 1,357 个复合物。RMSE、Matching 和 Ligand RMSD 越低越好，Stability 越高越好。

| 场景 | 模型 | RMSE | Matching | Stability | Ligand RMSD |
|---|---|---:|---:|---:|---:|
| T1 10→10 | ComplexMD | 1.2244 | 0.3923 | 86.4893 | 1.3830 |
| | 旧 BindMD | 1.2337 | 0.3923 | 86.4893 | 1.3916 |
| | NeuralMD | 2.1738 | 0.4010 | 86.1128 | 2.3032 |
| T2 80→20 | ComplexMD | 1.4277 | 0.4096 | 85.7218 | 1.5996 |
| | 旧 BindMD | 1.4468 | 0.4096 | 85.7219 | 1.6172 |
| | NeuralMD | 2.7992 | 0.4303 | 84.7050 | 2.9427 |
| T3 20→80 | ComplexMD | 2.0323 | 0.4890 | 83.0926 | 2.2472 |
| | 旧 BindMD | 2.1150 | 0.4890 | 83.0927 | 2.3220 |
| | NeuralMD | 4.8086 | 0.5919 | 78.2448 | 4.9963 |

相较旧 BindMD，ComplexMD 的 RMSE 在 T1、T2、T3 分别降低约 0.75%、1.32% 和 3.91%。相较 NeuralMD，分别降低约 43.7%、49.0% 和 57.7%。

NeuralMD 发布评估器与 ComplexMD 的绝对坐标参考系处理存在差异，因此绝对 RMSE 是工程基线而非无条件等价比较；Matching、内部距离和键长等刚体不变量更适合判断构象质量。

## GOAI 公开观测段因果回测

公开包不含未来真值。以下结果通过扣留观测段末尾作为伪未来得到，不是官方隐藏测试分数。

| 回测 | 学习位姿 World RMSE | 保持末帧 | 相对变化 |
|---|---:|---:|---:|
| T1 8→2 | 1.4039 | 1.4079 | -0.29% |
| T2 60→20 | 2.9611 | 2.9584 | +0.09% |
| T3 10→10 | 2.1222 | 2.1269 | -0.22% |

结果说明蛋白质位姿头学到了弱但可用的短程平移信号；长时程旋转漂移仍是主要限制。最终推理使用 0.25 的平移和旋转残差缩放。
